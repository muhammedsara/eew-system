Reducing False Alarms in Crowdsensed Earthquake Early Warning

with Hybrid Mobile-IoT Edge Intelligence

Research Implementation & Interactive Demo

📄 Abstract

This study proposes a hybrid Mobile-IoT Earthquake Early Warning (EEW) system that leverages weighted spatiotemporal consensus to minimize false alarms. By integrating low-cost IoT anchors with widespread crowdsourced mobile devices, the system achieves 98% false alarm reduction while maintaining high detection speed (<3s). The proposed weighted voting mechanism assigns higher reliability scores to fixed IoT sensors (w=0.7) compared to mobile devices (w=0.3), addressing the inherent noise and positioning uncertainty in smartphones. Experimental evaluation on 600 simulated scenarios demonstrates 94% True Positive Rate with only 2% False Positive Rate, outperforming mobile-only and IoT-only baselines.

System Architecture

Hybrid Architecture Workflow:

1. Edge Devices:
• Mobile phones (MEMS, 50Hz)
• IoT anchors (Calibrated, 100Hz)

2. Communication Layer:
• MQTT for real-time triggers
• WebSocket for dashboard

3. Consensus Protocol:
• DBSCAN spatial clustering
• 2s temporal windowing
• Weighted voting (w₍ₘₒᵦᵢₗₑ₎=0.3, w₍ᵢₒₜ₎=0.7)
• Time-adaptive threshold

4. Alert System:
• SMS, Push, API notification

🔧 Methodology

Spatial Clustering

DBSCAN(eps=5km, min_samples=3)

Groups nearby triggers to identify localized seismic activity

Temporal Windowing

2s sliding window

Aggregates triggers within time window for consensus

Weighted Voting

Score = Σ(w_i × c_i) / Σ(w_i)

w_mobile=0.3, w_iot=0.7
